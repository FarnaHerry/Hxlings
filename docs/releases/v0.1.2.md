# Hxlings v0.1.2

## Bug Fixes

- **Self-Contained Linux Runtime (`GLIBC_2.44` Startup Fix)**:
  - Switched Linux release packaging (`.tar.gz`, `.deb`, `.rpm`, `.AppImage`) from `--mode vendored` to `mcpp pack --mode self-contained`, bundling the matching `ld-linux-x86-64.so.2`, `libc.so.6`, `libm.so.6`, and `gconv/` runtime beside HuxerUI's `xim:*` GTK4/SQLite libraries so installed packages no longer fail with ``/lib64/libm.so.6: version `GLIBC_2.44' not found`` on host Linux distributions.
  - Resolved `HUXERUI_RESOURCES_DIR` automatically from `MCPP_BUNDLE_DIR` during `PreparePlatformStartup()` and `ResolveAppIconPngPath()`, fixing bundled resource lookup when Linux launches through the private dynamic linker (`/proc/self/exe` points to `ld-linux-x86-64.so.2`).
  - Sanitized self-contained wrapper variables (`MCPP_BUNDLE_DIR`, bundled `GCONV_PATH`, and bundled `LD_LIBRARY_PATH` entries) in `src/xlings_process.cppm` before spawning child `xlings` processes so host binaries continue using the host C runtime.
- **CI Regression Gates**: Added automated Linux `.tar.gz`, `.deb`, and `.AppImage` self-contained loader, libc/libm resolution, and resource checks in `.github/workflows/ci.yml`.
