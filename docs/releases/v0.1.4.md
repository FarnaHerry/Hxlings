# Hxlings v0.1.4

## Bug Fixes & Improvements (Windows)

- **Silent Background `xlings` Process Execution on Windows (No Console Flash)**:
  - Fixed visible terminal windows popping up on every `xlings` CLI call—and flashing in bursts during Hxlings' 5-way parallel startup `RefreshCore`—when `hxlings.exe` runs under `windows_subsystem = "windows"`.
  - Added a pure-C++23-module Windows process runner in `src/xlings_process.cppm` dynamically resolving `kernel32.dll` (`CreateProcessW` with `CREATE_NO_WINDOW`, `SW_HIDE`, MSVC-compliant argument/batch quoting, sanitized UTF-16 environment block merging, `spawn_mutex` handle-inheritance serialization, Job Object `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`, and streaming `PeekNamedPipe` reads with cancel support), verified by unit and live Windows process tests.
- **Self-Contained Windows `.msi` Installer (`EmbedCab="yes"`)**:
  - Replaced the 36 KB metadata-only `.msi` (whose payload was left in an external `cab1.cab` by `mcpp.dist.wix`'s default `.wxs`) with a custom WiX v5 `Package.wxs` in `build.mcpp` setting `<MediaTemplate EmbedCab="yes" />`, `app.ico` (`ARPPRODUCTICON`), Start Menu shortcut, and conditional Desktop shortcut (`CREATE_DESKTOP_SHORTCUT = 1`), verified via isolated `msiexec /a` extraction.
- **HuxerUI Custom Windows Installer UI in `-setup.exe`**:
  - Added the `platform/windows/package/` subpackage (`hxlings-installer.exe`) embedding HuxerUI's Material3 Windows Installer UI, `app.ico`, `hxlings.png` branding, system light/dark theme adaptation, 10 locale string tables, `mbanative.dll`, and MSVC runtime DLLs, chained into a WiX Burn bundle without `WixStandardBootstrapperApplication` and verified via `wix burn extract`.
