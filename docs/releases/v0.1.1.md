# Hxlings v0.1.1

## Highlights

- **Pure C++23 Modules Architecture**: Migrated `src/` to pure C++23 Modules (`0` preprocessor directives), declaring Windows GUI subsystem, entry point, and PE resources in `mcpp.toml`, and using `mcpplibs.os` for process spawning, environment sanitization, atomic config persistence, and native platform integration.
- **Fast Progressive Startup & Lazy Domain Loading**: Replaced sequential blocking startup with 5-way parallel `RefreshCore` (~10 ms initial render), offloading slow remote `list_index_versions` queries, package/SubOS detail fetches, `xlings config`, and `profile` snapshots to on-demand lazy loaders.
- **Decoupled App Settings, Theme Effects & Lightweight Tray Mode**:
  - Added local `settings.json` persistence in the user config directory with instant startup load.
  - Replaced single toggle with **Auto / Light / Dark** 3-state theme selector (`theme_auto`, `sun`, `moon` SVGs) featuring `CircularRevealTransition` click reveal animations and `FadeTransition` shortcut toggles.
  - Added cross-platform **System Tray** menu, **Close-to-Tray**, and **Lightweight Mode** (closes and retires the native UI window & renderer while keeping background tasks and tray alive; reopens cleanly via tray activation).
  - Moved version/runtime metadata and official links (`Hxlings`, `HuxerUI`, `xlings`) to the Settings **关于** section and added cross-platform PNG / `.ico` / `.icns` branding.
- **Cross-Platform Keyboard Shortcuts & macOS Adaptation**: Added native macOS (`⌘`) and Linux/Windows (`Ctrl`) shortcuts including `⌘Q` / `⌘W` / `⌘M` / `⌃⌘F`, plus a shortcuts catalog dialog in Settings.
- **CI/Release & Engineering Governance**: Added Linux `.tar.gz`/`.deb`/`.rpm`/`.AppImage`, Windows `.zip`/`.msi`/`-setup.exe`, and macOS `.tar.gz`/`.dmg` release artifacts, alongside `AGENTS.md`, `CLAUDE.md`, `project-memory/`, and on-demand `project-skills/`.
