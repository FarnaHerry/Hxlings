# Hxlings v0.1.5

## New Features & CLI GUI Coverage

- **Clickable External URLs (Default Browser Launch)**:
  - Added cross-platform `OpenExternalUrl` with safe URL validation/normalization (`http://` and `https://`) in `src/xlings_process.cppm` (Windows `shell32.dll` `ShellExecuteW`, macOS `/usr/bin/open` detached, Linux sanitized `xdg-open` detached).
  - Added `ExternalLinkRow` in `src/components.cppm` and upgraded `KeyValueRow` to render clickable browser links with one-click copy across Settings About (GitHub links), Installed/Store package metadata (`homepage`/`repo`), Index Repositories, and Network Endpoints.

- **Global Configuration, Network Probing & Script Tools**:
  - Settings Tab 1 (`xlings 全局配置`): Added CLI theme switcher (`xlings config --theme`), default runtime pinning (`xlings config --runtime`), and offline archive directory management (`--add-archives` / `--rm-archives`).
  - Settings Tab 2 (`环境诊断与维护`): Added network endpoint discovery (`interface network_endpoints`), URL connectivity/latency probe (`interface probe_url`), local automation script runner (`xlings script`), and home setup actions (`xlings self migrate`, `xlings self init`).
  - Indexes (`索引与配方`): Added stale/all local recipe cleanup actions (`xlings config --clear-xpkg stale|all`).

- **Complete SubOS Governance & Lifecycle GUI**:
  - Extended New SubOS modal with advanced creation options (`--from`, `--sandbox`, `--runtime`, `--abi`, `--storage`, `--proxy`, `--rootfs`, `--dry-run`).
  - Added SubOS toolbar dialogs for environment package diff (`subos diff`) and host/SubOS file copy (`subos cp`).
  - Added header lifecycle actions & dialogs for starting/stopping sessions (`subos start`/`stop`), upgrading editions (`subos upgrade [--to] [--dry-run]`), listing/rolling back root generations (`subos rollback [--list] [--to]`), rebinding runtime (`subos runtime`), and exporting/packing SubOS images (`subos export`/`subos pack`).
  - Added `--cwd` and `--timeout` options to SubOS command execution (`interface subos_exec`).
  - Added dedicated SubOS **策略 (`Policy`)** and **会话 (`Sessions`)** tabs covering kernel sandbox gates & effective status (`subos status`), full policy editor (`subos config`), pending request approval/denial (`subos requests`/`approve`/`deny`), active sessions (`subos ps`), health doctor & fix (`subos doctor [--fix]`), detailed info panel (`subos info`), and session audit reports (`subos report`).
