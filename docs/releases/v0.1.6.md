# Hxlings v0.1.6

## Fixes & New Features

- **Network Connectivity Probe Fix**:
  - Fixed `xlings interface probe_url` failing with `probe_url failed (exit 2) with no error detail on the stream` when `socket_timeout_ms > 3000` was passed (now defaults to omitting `socket_timeout_ms` and clamps explicit positive timeouts to `100..3000` ms via `BuildProbeUrlArgs` in `src/xlings_client.cppm`).
  - Improved `NetworkProbeCard` error/timeout status badges and toast reporting when endpoints are unreachable or commands fail.

- **In-App Software Self-Update (Settings → 关于)**:
  - Added pure C++23 module `hxlings.updater` (`src/app_updater.cppm`) plus streaming GitHub Latest Release checks, asset selection across Windows (`-setup.exe > .msi > .zip`), macOS (`.dmg > .tar.gz`), and Linux (`.AppImage` / `.deb` / `.rpm` / `.tar.gz`), download cancellation, FIPS 180-4 SHA-256 verification against `SHA256SUMS.txt`, and native apply/install helpers (`OpenLocalPath`, `LaunchDetachedExecutable`).

- **Tray & Native Menu Light/Dark Theme Sync**:
  - Added `ApplyPlatformThemeMode` in `src/platform_icon.cppm` wired to `Auto` / `Light` / `Dark` changes across Windows (`uxtheme.dll` + `dwmapi.dll`), macOS (`[NSApp setAppearance:]`), and Linux GTK (`gtk-application-prefer-dark-theme` via variadic `g_object_set`).

- **Child Process RAII Hardening & macOS CI Verification**:
  - Managed Win32 environment overrides, handles, and active PID state with exception-safe RAII guards (`Win32EnvGuard`, `Win32HandleGuard`, `PidResetGuard`) in `src/xlings_process.cppm`.
  - Added macOS CI `codesign --verify --deep --strict` and DMG mount verification gates alongside an in-repo Homebrew Cask (`Casks/hxlings.rb`).
