# Hxlings v0.1.7

## Fixes & Improvements

- **Fix `xlings self update --yes` Exit 127 Under Desktop Launchers**:
  - Generalized child-process `PATH` sanitization in `src/xlings_process.cppm` (`BuildSanitizedSearchPath` / `BuildSanitizedEnvOverrides`) across Linux, macOS, and Windows to prepend the resolved executable's directory alongside `$XLINGS_HOME/{subos/current/bin,bin}` and `$HOME/.xlings/{subos/current/bin,bin}` while stripping bundled `.mcpp/registry` and `MCPP_BUNDLE_DIR` entries.
  - Prevents `xlings self update --yes` (which internally invokes bare `xlings` subcommands via `sh -c`) from failing with exit code `127` when Hxlings is launched from a GUI desktop entry with a minimal `PATH`.

- **Unified Inline `SearchBox` Component**:
  - Extracted reusable `SearchBox` (`src/components.cppm`) and `CloseIcon` (`src/icons.cppm`) across Store, Packages, and SubOS pages, moving the clear action inside the trailing edge of the input with a smaller cross icon (`14dp` vs `18dp` search icon) and a circular hover state layer.

- **Light-Mode Disabled Legibility & Consolidated Theme Palette**:
  - Consolidated hardcoded UI colors into `AppThemeSpec` and `StatusPalette` (`src/theme.cppm`) and removed double alpha attenuation on disabled `ActionButton` / `TitleIconAction` controls so disabled Ghost actions (such as `TaskConsole` Copy/Clear when logs are empty) stay clearly legible in Light mode.

- **Virtual Scrolling in Store Search Results**:
  - Replaced manual "显示更多" pagination in `src/page_store.cppm` with `VirtualList` + `UseScrollController()` so large package catalogs scroll and load smoothly on demand.
