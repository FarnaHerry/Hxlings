# Hxlings v0.1.3

## Bug Fixes

- **Native System-Dependency `.deb` & `.rpm` Packages (`--mode system`, ~3–4 MB)**:
  - Lowered `hxlings` Linux x86_64 ELF GLIBC symbol floor from `GLIBC_2.43` to **`GLIBC_2.38`** by wrapping `sqrtf`, `atan2f`, and `remainder` to `GLIBC_2.2.5` via a generated C compatibility shim in `build.mcpp` (compatible with Ubuntu 24.04+, Debian 13+, Fedora 40–44+, RHEL 10+).
  - Switched Linux `.deb` and `.rpm` release packages back to `mcpp pack --mode system`, removing the 35 MB bundled `.so` closure and declaring native distribution dependencies (`libgtk-4-1 (>= 4.14)`, `libepoxy0 (>= 1.5)`, `libsoup-3.0-0 (>= 3.0)`, `libpangoft2-1.0-0`, `libfontconfig1` for `.deb`; `lib*.so.*()(64bit)` SONAME capabilities for `.rpm`), enabling native host GTK4 and Mesa EGL 1.5 (`GskGLRenderer`) hardware rendering.
- **Fixed Pink Icons / Cards Rendering in Portable Self-Contained `.tar.gz` & `.AppImage`**:
  - Appended host GPU library directories (`/usr/lib/x86_64-linux-gnu:/usr/lib64:/lib/x86_64-linux-gnu:/lib64`) after `$here/lib` in the self-contained loader `--library-path`, allowing `libepoxy` to `dlopen()` host Mesa OpenGL (`GskNglRenderer`) instead of falling back to `GskCairoRenderer` (`#FF69B4` unsupported mask/fill nodes).
  - Also sanitized bundled `LOCPATH` alongside `GCONV_PATH`, `LD_LIBRARY_PATH`, and `MCPP_BUNDLE_DIR` before spawning `xlings` child processes in `src/xlings_process.cppm`.
- **CI Regression Gates**: Verified `.deb` installation with real `apt-get install`, `GLIBC <= 2.38` symbol floor via `readelf -V`, `/usr/bin/ldd` resolution, native RPM SONAME declarations, and self-contained launcher GPU search paths.
