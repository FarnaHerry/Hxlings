安装与软件源 GPG 公钥 setup-repo.sh

安装与软件源

一键导入 Hxlings 专属 GPG 公钥并配置系统软件源（安装到 /opt/hxlings，支持 dnf / apt / zypper 随系统自动更新）：

curl -fsSL {{BASE_URL}}/setup-repo.sh | sudo bash

GPG 公钥指纹：{{GPG_FPR}} · gpg.key · 仅配置源加 --repo-only，移除加 --uninstall

查看手动配置 Fedora/RHEL (dnf)、openSUSE (zypper) 与 Debian/Ubuntu (apt) 命令 
# Fedora / RHEL (x86_64)
sudo rpm --import {{BASE_URL}}/gpg.key
sudo tee /etc/yum.repos.d/hxlings.repo <<'REPO'
[hxlings]
name=Hxlings Repository
baseurl={{BASE_URL}}/rpm/$basearch/
enabled=1
gpgcheck=1
repo_gpgcheck=0
gpgkey={{BASE_URL}}/gpg.key
REPO
sudo dnf install -y hxlings
# openSUSE (x86_64)
sudo rpm --import {{BASE_URL}}/gpg.key
sudo tee /etc/zypp/repos.d/hxlings.repo <<'REPO'
[hxlings]
name=Hxlings Repository
baseurl={{BASE_URL}}/rpm/$basearch/
enabled=1
autorefresh=1
gpgcheck=1
repo_gpgcheck=0
gpgkey={{BASE_URL}}/gpg.key
REPO
sudo zypper refresh hxlings && sudo zypper install -y hxlings
# Debian / Ubuntu (amd64)
curl -fsSL {{BASE_URL}}/gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/hxlings.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/hxlings.gpg] {{BASE_URL}}/apt stable main" | sudo tee /etc/apt/sources.list.d/hxlings.list
sudo apt update && sudo apt install -y hxlings

无需管理员权限，从 GitHub Releases 下载并校验 SHA256SUMS.txt 后运行自包含 AppImage 或 .tar.xz 压缩包：

# 下载并运行 AppImage (x86_64)
curl -fsSLO {{REPO_URL}}/releases/download/v{{VERSION}}/hxlings-{{VERSION}}-linux-x86_64.AppImage
chmod +x hxlings-{{VERSION}}-linux-x86_64.AppImage
./hxlings-{{VERSION}}-linux-x86_64.AppImage

# 或解压运行 .tar.xz 便携归档
curl -fsSLO {{REPO_URL}}/releases/download/v{{VERSION}}/hxlings-{{VERSION}}-linux-x86_64.tar.xz
tar -xJf hxlings-{{VERSION}}-linux-x86_64.tar.xz
./hxlings-{{VERSION}}-linux-x86_64/hxlings

所有发行文件均随附 SHA256SUMS.txt，建议下载后执行 sha256sum -c --ignore-missing SHA256SUMS.txt。

支持 Apple Silicon (arm64)，可通过 Homebrew Cask、DMG 或 .tar.xz 安装（首次打开需清除隔离属性）：

brew tap farnaherry/hxlings {{REPO_URL}}
brew install --cask farnaherry/hxlings/hxlings
xattr -dr com.apple.quarantine /Applications/Hxlings.app

亦可直接从 Releases 下载 hxlings-{{VERSION}}-macos-arm64.dmg 或 .tar.xz 便携包。

提供基于 HuxerUI 定制界面的 WiX Burn 安装向导（-setup.exe）、企业静默部署 .msi 以及免安装 .zip：

# winget / MSI 静默安装或直接运行图形安装向导
curl.exe -fsSLO {{REPO_URL}}/releases/download/v{{VERSION}}/hxlings-{{VERSION}}-windows-x86_64-setup.exe
.\hxlings-{{VERSION}}-windows-x86_64-setup.exe

Releases 同时提供 hxlings-{{VERSION}}-windows-x86_64.msi 与免安装 .zip 归档。

核心特性

概览总览 & 健康诊断

并发渐进加载 xlings 版本、当前 SubOS、镜像源与关键路径统计，内置一键 doctor --fix 修复、缓存清理与代际快照回滚。

多版本软件管理 & 批量清理

按软件聚合多版本状态，一键切换活跃版本（use）、全量扫描并批量更新、带 --dry-run 预演的过期版本清理与批量卸载。

软件商店 & 依赖计划预览

虚拟滚动检索 xlings 包索引与分类，选择目标版本与 SubOS，安装前预览完整依赖计划并实时流式展示进度。

SubOS 子环境 & 索引配方

创建/切换/删除 SubOS，查看 Shims 与环境变量、在沙箱内执行命令，并支持全局索引仓库同步、快照固定与本地 .lua 配方注册。

LubanOS 蓝图栈工作台

内置交互式 JSON/TOML Blueprint Stack 编排与目录工作区，按需懒加载节点状态，统一驱动环境部署与模板管理。

纯 C++23 Modules & 轻量托盘

零头文件纯模块架构搭配跨平台系统托盘与轻量级后台驻留模式，三态主题、自定义强调色与客户端设置本地解耦存储。
